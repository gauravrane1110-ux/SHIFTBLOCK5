# 4THRIVES Team Portfolio

## Open in VS Code
1. Extract the ZIP.
2. Open the `4THRIVES_Portfolio` folder in VS Code.
3. Open `index.html`.
4. For the best experience, install the VS Code extension **Live Server** and choose **Open with Live Server**.

## Files
- `index.html` — website structure/content
- `style.css` — design, responsive layout and animations
- `script.js` — mobile navigation and reveal animations
- `assets/4thrives-logo.jpeg` — the uploaded 4THRIVES artwork
- `assets/gaurav.svg` — illustrated placeholder portrait
- `assets/shruthik.svg` — illustrated placeholder portrait
- `assets/palak.svg` — illustrated placeholder portrait
- `assets/shraddha.svg` — illustrated placeholder portrait

## Personal photos
The four SVG portraits are original generic illustrations, not likenesses of the real team members. Replace each SVG in the `assets` folder with a JPG/PNG photo and update the matching `<img src="...">` in `index.html` if you want real team photos.

## Contact
The demo contact button uses `4thrives@example.com`. Replace it with your real team email in `index.html`.
